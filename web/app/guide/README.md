# 交互式操作指引

入口：登录页和登录后顶部「使用手册」弹窗中的「开始操作指引」。

## 体验设计

使用游戏任务式的高亮与遮罩，让用户在实际表单里完成操作。右侧提示卡提供当前目标、示例输入、阶段进度和退出入口。点击、输入、保存分别验证：点击目标后继续；输入有效内容后可继续；保存操作必须成功才进入下一步。

体验约 8 分钟，共 55 步、五个阶段：

1. 准备资料：认识预置示例简历，录入并保存 JD，关联简历与 JD 创建面试包。项目证据卡为可选资料。
2. 真实面试：创建记录、关联面试包、填写时间及备注，认识复盘状态与面试结果；进入问答记录，手动添加问题、回答和自评，展开核对；再粘贴多组文本，按空行分段加入，确认原有问答仍然保留。
3. 模拟作答：选择面试包，将主问题数量设为 1，开始文本模拟，输入回答并自评，提交回答。
4. 查看复盘：展开逐题反馈，结束并确认保存，查看本场回答与反馈。
5. 定向训练：发起示例分析，查看成果量化诊断，创建关联训练任务，更新为已完成。

真实面试体验覆盖手动添加和文本分段；录音导入及 AI 文本识别只说明入口、核对与确认流程，不上传真实录音或调用 AI。文本模拟继续演练训练闭环；语音模拟、知识库与 AI 对话通过手册介绍。

## 实现与边界

- `/guide` 是公开的独立体验区，无需登录，复用资料库、真实面试记录、文本模拟、薄弱点的现有页面组件及校验逻辑。
- 仅当当前路径严格为 `/guide` 时，统一 API 入口使用内存示例数据；未支持的接口、文件下载与流式调用直接拒绝，不回落到真实服务。
- 教学题目、反馈和分析结果明确标注为示例，不根据实际输入调用模型。回答原文会保留在本次体验中。
- 不新增依赖，不写入账户、浏览器持久存储或后端；退出、刷新或重新开始后清空示例数据。刷新从头开始。
- 资料分类与薄弱点切换保留当前路径，体验操作不会离开 `/guide`。遮罩与键盘焦点控制限制到当前目标及指引卡，Escape 可退出。
- 真实面试页面在体验区通过 `interviewPath` 参数切换列表、创建、详情和问答视图；创建成功后由指引切换视图，正式页面仍按原路由跳转。文本分段与实际接口保持一致：空行分组，第一行是问题，其余行是回答。
- 支持深浅主题、窄屏布局和减少动态效果设置。退出回到原页面；完成后可前往资料库，未登录用户回到登录页。

## 验证

在 `web` 目录运行：

```powershell
pnpm lint
node --test lib/guide-demo.test.cjs components/AppShell.test.cjs app/interviews/page.test.cjs app/mock-interviews/page.test.cjs app/weaknesses/page.test.cjs lib/api.test.cjs
```

浏览器验收：从使用手册进入，走完所有步骤；检查示例填入、空输入拦截、跨页面高亮定位、保存确认、重新开始和退出。
